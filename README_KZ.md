# STEERING RACE 3D — Python компьютерлік ойын

**Браузер, HTML, JS немесе WebSocket қажет емес.** Бұл — бөлек терезеде ашылатын жергілікті 3D жарыс ойыны. 3D көрінісі Ursina/Panda3D, камераны тануы OpenCV/MediaPipe көмегімен жұмыс істейді.

## PyCharm-да іске қосу

1. ZIP-ті ашып, `SteeringRace3D` папкасын PyCharm арқылы `File → Open` көмегімен аш.
2. **Python 3.10 (64-bit)** таңда. `Location` жолында **жаңа, бос** `D:\SteeringRace3D\.venv` папкасы болуы керек. Бұрын жасалған виртуалды ортаны қолданғың келсе, `Existing interpreter` таңда.
3. PyCharm Terminal ашып, мына командаларды орында:

```powershell
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

4. `main_3d.py` файлын `Run` арқылы іске қос.
5. Камераға екі қолыңды көрсетіп, қиялдағы рульді **9 және 3** сағат бағытындағыдай ұста. `C` басып калибрле; `Enter` басып жарысты баста.

Егер алдыңғы жобаның виртуалды ортасын пайдалансаң, `numpy` және OpenCV нұсқалары қайшы келуі мүмкін. Сондықтан жаңа `.venv` пайдаланған дұрыс.

## Басқару

| Перне / қимыл | Нәтижесі |
|---|---|
| Екі қолды бұру | Машинаны оңға/солға бұру |
| `C` | Екі қолды түзу ұстап рульді калибрлеу |
| `A`, `D` немесе `←`, `→` | Камера табылмаса, пернетақтамен бұру |
| `M` | Камера / пернетақта режимдерін ауыстыру |
| `W`, `S` немесе `↑`, `↓` | Жылдамдықты арттыру / тежеу |
| `Enter` | Жарысты бастау |
| `P` | Уақытша тоқтату / жалғастыру |
| `R` | Жарысты қайта бастау |
| `Esc` | Ойыннан шығу |

**Ескерту.** MediaPipe екі алақанды таниды, рульдің нақты пластик/физикалық нысанын танымайды. Екі қолдың арасындағы көлбеу сызық бұрылу бағытын анықтайды; қолдарыңды камера кадрының ішінде әрі бір-бірінен алшақ ұста.

## Ойын мүмкіндіктері

- Бір терезеде толық 3D жол және 3D көліктер (дайын модель файлдары қажет емес)
- Өзгеретін жылдамдық, жолдағы басқа машиналар, соқтығысу, 3 мүмкіндік
- Камераның шағын тікелей көрінісі ойынның жоғарғы оң жағында
- Екі қолдың виртуалды руль бұрышын өлшеу, `C` калибрлеу, автоматты keyboard fallback
- Жылдамдық, қашықтық және басып озу көрсеткіштері

## Қате туындаса

- `ModuleNotFoundError: No module named 'ursina'`: сол виртуалды ортада `python -m pip install -r requirements.txt` орында.
- `ImportError: DLL load failed`: жаңа Python 3.10 64-bit `.venv` жаса және Windows Visual C++ Redistributable орнатылғанын тексер.
- `NO CAMERA`: камераны пайдаланатын Zoom/браузер бағдарламаларын жап, Windows-та камераға рұқсат бер. Ойын `A/D` пернелерімен жүре береді.
- `SHOW TWO HANDS`: камерадан алысырақ тұрып, алақандарды жарық жерде көрсет; алақандардың арасы жеткілікті болсын.
- Алдыңғы жобада OpenCV 5 болса, осы жоба үшін **жаңа** орта қолдан.
